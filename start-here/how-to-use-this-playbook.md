# How to Use This Playbook

## How it is organized

Every system follows the same pattern, so people always know where to look:

1. **Quick Start**: what the system is and what it is used for.
2. **Logging in**: where it lives and how to access it.
3. **How-To Guides**: one page per task.
4. **Troubleshooting**: one page per known problem.

## Finding things

* Use the search bar first.
* When something breaks, go to **Incidents & Troubleshooting**.

## Keeping it alive

* If you answer the same question twice, write a page for it.
* If a page is wrong, fix it the same day.
* Every page should say who owns it.

{% hint style="info" %}
Never put passwords in the playbook. Write where the password is stored (for example, the team password manager).
{% endhint %}
