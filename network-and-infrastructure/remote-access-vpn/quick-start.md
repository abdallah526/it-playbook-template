# Quick Start

### Overview

* **Purpose**: Enables secure remote access to the company network using Sophos VPN solutions.
* **Access**: Managed via the Sophos VPN Portal at https://\[firewall-ip]:4646; credentials are Active Directory username (or user folder name) and password.
* **Key Areas**: Features include Sophos Connect client for Windows/macOS and OpenVPN support for various devices.

{% hint style="info" %}
Ensure port 4646 is open on the firewall. Contact the IT admin for Active Directory credential issues.
{% endhint %}
