# Quick Start

### Overview

* **Purpose**: Sophos Firewall offers advanced network security, including threat protection, SDWAN routing, and centralized management for RED (Remote Ethernet Device) connections.
* **Access**: Access the Sophos Firewall web admin console using a web browser (e.g., Chrome, Firefox). The IP address and credentials are provided by the IT admin via Keeper Security.
* **Core Features**:
  * SDWAN routing for optimized traffic management (e.g., routing specific websites through designated gateways).
  * Log Viewer for real-time monitoring and troubleshooting of network events.
  * Ping diagnostics from the gateway to test connectivity.
  * RED connection management for secure site-to-site VPN.
  * Centralized management via Sophos Central for multi-device control.
* **System Requirements**: A PC with internet access, Sophos Firewall device (e.g., XG or XGS series), and valid admin credentials.

{% hint style="info" %}
Ensure you retrieve the Sophos Firewall credentials from Keeper Security before attempting to log in. For detailed configuration instructions, refer to the How-To Guide section (e.g., Route Website from Specific Gateway).
{% endhint %}
