# Install RSAT

### Prerequisites

* A Windows PC (e.g., Windows 10 or 11 Pro/Enterprise).
* Administrative privileges on the PC.
* Internet connection (for downloading RSAT).
* A domain-joined PC or access to the domain controller.



{% hint style="info" %}
If RSAT installation fails, ensure your Windows version supports RSAT (Pro/Enterprise editions only). You may need to download RSAT manually from Microsoft’s website if the feature is unavailable.
{% endhint %}
