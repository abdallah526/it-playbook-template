# Quick Start

### Overview

Active Directory (AD) is a Microsoft directory service for managing users, computers, and other resources in a Windows domain network. It enables centralized administration of user accounts, passwords, PC domain memberships, DHCP services, and Windows deployment via WDS. This section provides guidance on installing Remote Server Administration Tools (RSAT), managing user accounts, joining PCs to the domain, configuring DHCP, troubleshooting common issues, and deploying Windows using WDS.

### Key Features

* **User Management**: Create, disable, and reset passwords for user accounts.
* **Domain Management**: Join or remove PCs from the domain.
* **DHCP Configuration**: Set up DHCP for IP address allocation.
* **Windows Deployment**: Use WDS to deploy Windows on PCs.
* **Troubleshooting**: Resolve common Active Directory issues.

### Next Steps

* Start with Install RSAT to set up management tools on your PC.
* Explore How To Guide for detailed instructions on tasks like creating user accounts or configuring DHCP.
* Refer to Troubleshooting for help with common issues.
* Use Windows Deployment Service (WDS) to deploy Windows on PCs.

{% hint style="info" %}
Ensure you have administrative privileges on the domain controller. Back up AD data before making changes.
{% endhint %}
