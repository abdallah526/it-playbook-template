# Quick Start

### Overview

* **Purpose**: PRTG is a network monitoring tool by Paessler that tracks IT infrastructure performance, including bandwidth, devices, and applications, to identify and resolve issues.
* **Key Features**:
  * **Monitoring**: Monitors devices (servers, routers, switches) using protocols like SNMP, WMI, and SSH.
  * **Data Collection**: Gathers data on bandwidth, traffic, and system performance via sensors.
  * **Alerts**: Sends notifications (email, SMS) when thresholds are breached.
  * **Visualization**: Offers dashboards, maps, and reports for real-time insights.
* **Use Cases**:
  * Monitor network uptime and performance.
  * Detect bandwidth bottlenecks.
  * Troubleshoot device failures.
