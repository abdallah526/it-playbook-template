# Quick Start

### Overview

* **Purpose**: PDQ Inventory is a Windows-based tool by PDQ.com that scans, collects, and organizes data from on-prem Windows machines (requires .NET 4.5.2 or higher) to streamline device management and deployments.
* **Key Features**:
  * **Scanning**: Collects hardware, software, and system data via standard scans (e.g., last scan within 7 days).
  * **Dynamic Collections**: Groups devices automatically based on criteria (e.g., old software versions, low disk space).
  * **Reporting**: Pulls detailed reports on any scanned data for quick insights.
  * **Automation**: Integrates with PDQ Deploy to automate software updates and maintenance tasks.
* **Use Cases**:
  * Track software versions across devices.
  * Identify machines with low disk space.
  * Prepare for targeted software deployments.
