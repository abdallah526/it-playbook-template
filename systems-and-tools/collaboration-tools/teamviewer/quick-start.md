# Quick Start

## Overview

TeamViewer is a remote access and support tool used by the **IT team** to manage company devices remotely. It allows IT support to:

* Provide **remote troubleshooting** for employees.
* Set up **unattended access** for IT-managed devices.
* Securely connect to company computers **using the IT department’s licensed account**.
