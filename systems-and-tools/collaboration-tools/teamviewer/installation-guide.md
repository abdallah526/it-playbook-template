# Installation Guide

#### **Installing TeamViewer on Windows**

1. Download **TeamViewer** from [https://www.teamviewer.com/en/download/windows/](https://www.teamviewer.com/en/download/windows/).
2. Run the installer (`TeamViewer_Setup.exe`) and choose:
   * **Installation Type:** Default installation
   * **Usage:** Company / Commercial Use
3. Click **Accept – Next**, then wait for the installation to complete.

{% hint style="info" %}
If prompted, allow **TeamViewer** through the Windows Firewall.
{% endhint %}

#### **Installing TeamViewer on macOS**

1. Download **TeamViewer** from [https://www.teamviewer.com/en/download/macos/](https://www.teamviewer.com/en/download/macos/)
2. Open the **.dmg file** and move TeamViewer to the **Applications folder**.
3. Open **System Settings → Privacy & Security** and enable:
   * **Accessibility** (Allows control of the mouse & keyboard)
