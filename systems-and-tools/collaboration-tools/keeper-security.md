# Keeper Security

### Prerequisites

* A company email address (e.g., yourname@company.com) to receive an invitation from the IT admin.
* Internet connection.
* A web browser (e.g., Chrome or Firefox) with the Keeper extension capability.
* Keeper Security invitation email from your IT admin.

### Steps

1. **Accept the Invitation**:
   * Open the invitation email sent by your IT admin.
   * Click the activation link to start the account setup process.
2. **Create a Password**:
   * Follow the link to set a master password for your Keeper account.
   * Ensure the password is strong and unique, then confirm it.
3. **Activate the Account**:
   * Complete any additional setup steps (e.g., security questions or two-factor authentication).
   * Verify your account activation via email or the Keeper web interface.
4. **Install the Chrome Extension**:
   * Open Chrome and go to the Chrome Web Store.
   * Search for "Keeper Password Manager & Digital Vault" and click "Add to Chrome."
   * Pin the extension to your toolbar for easy access.
5. **Log In and Verify**:
   * Click the Keeper extension icon and log in with your master password.
   * Confirm autofill works for saved passwords (e.g., network device accounts).

{% hint style="info" %}
Keeper Security is used to store and share passwords for accounts and network devices within the IT department. Ensure you receive the invitation from your IT admin before starting. Contact your IT admin if you don’t receive the invitation or encounter setup issues.
{% endhint %}
