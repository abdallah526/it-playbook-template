# Quick Start

### Overview

* **Purpose**: ZKTeco BioTime is a web-based platform designed for time and attendance management, supporting biometric devices like fingerprint and facial recognition scanners.
* **Server Access**: Access the BioTime server at `http://172.20.31.30:8081` using a web browser (e.g., Chrome, Firefox).
* **Core Features**:
  * Real-time monitoring of employee clock-ins and clock-outs.
  * Supports up to 500 biometric devices (e.g., fingerprint devices) for large-scale deployments.
  * Cloud-based communication via ADMS (Access Data Management Service) for remote device management.
  * Employee self-service mobile app (BioTime Mobile) for iOS and Android.
  * Comprehensive attendance reports and shift scheduling.
* **System Requirements**: A PC with internet access, a configured BioTime server, and ZKTeco devices connected to the network (preferably using DHCP for dynamic IP assignment).

{% hint style="info" %}
Ensure the BioTime server at `http://172.20.31.30:8081` is accessible from your network. For detailed setup instructions, refer to the How-To Guide section (e.g., Configure Fingerprint Device in BioTime).
{% endhint %}
