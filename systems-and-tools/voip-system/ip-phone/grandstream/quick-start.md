# Quick Start

### Overview

Grandstream IP phones are used for VoIP communication within the company, integrating with the PBX server (SIP server: 172.20.31.10:5060). This section provides guidance on powering on, configuring settings, adjusting date and time, logging into extensions, performing factory resets, and troubleshooting common issues. The structure is designed to accommodate future additions.

### Key Features

* **SIP Integration**: Connects to PBX server for VoIP calls.
* **Scalability**: Flexible for adding new guides or troubleshooting scenarios.

### Next Steps

* Start with Power On to activate your Grandstream phone.
* Proceed to Configure Settings for SIP server setup.
* Use Adjust Date & Time to set the correct time.
* Follow Login to Extension to activate your extension.
* Refer to Reset Factory for troubleshooting or reconfiguration.
* Check Registration Failure under Troubleshooting for common issues.
