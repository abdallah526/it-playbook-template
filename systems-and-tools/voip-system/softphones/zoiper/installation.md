# Installation

### Prerequisites

* A macOS device with an active internet connection.
* Administrative privileges to install software on the macOS device.
* Approximately 50 MB of free disk space for the Zoiper installation.

### Steps

1.  **Download Zoiper**:

    * Open a web browser on your macOS device.
    * Navigate to the official Zoiper website (https://www.zoiper.com/en/voip-softphone/download/current).
    * Scroll to the macOS section and click the "\[Download]" button under the Free version.
    * If the download doesn’t start automatically, click "Click here if it doesn’t" to initiate the download.

    <figure><img src="../../../../.gitbook/assets/image (218).png" alt=""><figcaption></figcaption></figure>

    <figure><img src="../../../../.gitbook/assets/image (219).png" alt=""><figcaption></figcaption></figure>
2.  **Install Zoiper**:

    * Locate the downloaded file (e.g., "Zoiper.dmg") in your Downloads folder.
    * Double-click the .dmg file to mount the disk image.

    <figure><img src="../../../../.gitbook/assets/image (220).png" alt=""><figcaption></figcaption></figure>

    <figure><img src="../../../../.gitbook/assets/image (221).png" alt=""><figcaption></figcaption></figure>

    <figure><img src="../../../../.gitbook/assets/image (222).png" alt=""><figcaption></figcaption></figure>

    * A verification prompt will appear, just type in your password and click \[ Install Software ] button to continue forward with the installer.

    <figure><img src="../../../../.gitbook/assets/image (223).png" alt=""><figcaption></figcaption></figure>

    * Just wait until the installer finishes.

    <figure><img src="../../../../.gitbook/assets/image (224).png" alt=""><figcaption></figcaption></figure>

    * Once you see this screen, the installation is complete. Click the \[ Close ] button and run Zoiper

    <figure><img src="../../../../.gitbook/assets/image (225).png" alt=""><figcaption></figcaption></figure>



1. **Launch Zoiper**:
   * Open the Applications folder and double-click the Zoiper icon to launch the app.
   * If prompted with a message to buy a paid version, click "Continue as a Free user" at the bottom of the window.
   * Follow any initial setup prompts (e.g., audio configuration wizard) or skip them to proceed to the main interface.
2. **Verify Installation**:
   * Confirm that the Zoiper interface opens, displaying the dialpad or settings menu.
   * Check that no error messages appear during launch.

{% hint style="info" %}
Ensure the macOS device is updated to the latest version for compatibility. If the app fails to install, verify the downloaded file’s integrity or re-download it. Contact your IT admin if you encounter permission issues during installation.
{% endhint %}
