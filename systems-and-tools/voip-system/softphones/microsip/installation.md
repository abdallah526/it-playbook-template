# Installation

### Prerequisites

* Windows device (Windows 10/11 recommended for IT-managed systems).
* Administrative privileges.
* Access to the IT shared drive or MicroSIP download link.

### Installation Steps

1. **Download MicroSIP**:
   * Access the official site: [https://www.microsip.org/downloads](https://www.microsip.org/downloads).
   * Download the latest `.exe` (e.g., "MicroSIP-3.21.3.exe").
   * Alternatively, use the IT shared drive: \\\FILESERVER\IT$.

<div align="left"><figure><img src="../../../../.gitbook/assets/image (164).png" alt="" width="563"><figcaption></figcaption></figure></div>

1. **Run Installer**:
   * Right-click the `.exe` and select "Run as Administrator."
   * Approve UAC prompt if displayed.
2.  **Configure Installation**:

    * Select language and click "Next."
    * Choose install directory (e.g., `C:\Program Files\MicroSIP`) and click "Next."
    * Click "Install" and wait for completion, then "Finish."



    <div align="left"><figure><img src="../../../../.gitbook/assets/image (165).png" alt="" width="441"><figcaption></figcaption></figure></div>
3.  **Verify Installation**:

    * Launch MicroSIP and check for the main interface.
