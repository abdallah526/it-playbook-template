# Quick Start

### Overview

MicroSIP is a lightweight VoIP softphone integrated with the company's VoIP system\
(SIP Server: `172.20.31.10`). The IT team uses it to manage SIP accounts and make calls, supporting call center operations and communication between branches.

### Next Steps

* Install MicroSIP using the [Installation Guide](installation.md).
* Configure a SIP account with the How-To Guides > [Adding a SIP Account.](how-to-guides/add-sip-account.md)
* Place a call with How-To Guides > [Making a Call](how-to-guides/make-a-call.md).

{% hint style="info" %}
Contact the VoIP admin for SIP credentials and check Troubleshooting for issues.
{% endhint %}
