# Make a Call

#### Prerequisites

* SIP account configured (see above).
* Test SIP extension (e.g., `1002@172.20.31.10`).

#### Steps:

1. **Open MicroSIP**:
   * Ensure "Online" status.
2. **Dial Number**:
   * Enter the calling number (eg:.`677`) in the dial pad.
3. **Initiate Call**:
   * Click the green "Call" button or press "Enter."
   *

       <div align="left"><figure><img src="../../../../../.gitbook/assets/image (161).png" alt="" width="221"><figcaption></figcaption></figure></div>
4. **Manage Call**:
   * Use "Mute" or "Hold" buttons as needed.
   * End with the red "End" button.
5. **Verify**:
   * Confirm audio with a test call to another IT-managed device.
