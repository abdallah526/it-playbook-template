# PBX Server

The PBX server runs every extension, queue and call recording. Start with the Quick Start, then use the guides to manage extensions and queues or fix common issues.

{% hint style="info" %}
These guides use Issabel, an open-source PBX, as the example. Menu names differ on other systems such as FreePBX or 3CX, so update the steps to match yours.
{% endhint %}
