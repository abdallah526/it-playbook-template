# Create Callback Extension

### Prerequisites

* Logged into PBX admin (see[ Logging into PBX Admin)](../logging-into-pbx-admin.md).
* A web browser (e.g., Chrome, Firefox).
* A unique extension number (e.g., SIP/307) and a name for the callback extension.

### Steps

1. **Navigate to Callback Extensions**:
   * From the main menu, go to "Call Center" > "Agent Options" > "Callback Extensions."
2.  **Start Creating a New Callback Extension**:

    * Click the "+ New callback extension" button.



3. **Fill in the Required Fields**:
   * In the "Callback extension:" field, enter the extension number (e.g., "SIP/307").
   * In the "Password:" field, enter a secure password.
   * In the "Name:" field, enter the name of the extension (e.g., "Callback Agent 1").
   * In the "Retype password:" field, re-enter the password to confirm.
4.  **Save the Extension**:

    * Click the "Save" button to create the callback extension.
    * Ensure no error messages appear, and the new extension appears in the list.

5. **Verify the Extension**:
   * Check the "Callback Extensions" list to confirm the new extension (e.g., "SIP/307") is added with the correct status.
