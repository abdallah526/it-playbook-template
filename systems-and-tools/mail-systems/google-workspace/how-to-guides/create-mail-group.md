# Create Mail Group

### Prerequisites

* Admin access to the Google Workspace Admin Console.
* A verified domain (e.g., yourcompany.com).
* A web browser (e.g., Chrome, Firefox).

### Steps

1. **Log in to Admin Console**:
   * Go to `https://admin.google.com/` and log in with admin credentials.
2. **Navigate to Groups**:
   * Click "Groups" from the left menu.
   *

       <figure><img src="../../../../.gitbook/assets/image (244).png" alt=""><figcaption></figcaption></figure>
3.  **Add a New Group**:

    * Click the "+" button or "Create Group."
    * Enter the group name (e.g., support@yourcompany.com) and description.

    <figure><img src="../../../../.gitbook/assets/image (245).png" alt=""><figcaption></figcaption></figure>
4.  **Access Type**:

    * Choose the type of Group (Public, Team, etc.)
    * Select Access Settings
    * Choose "Only Invite Users" for **who can join the group**
    * Enable Allow Members outside the organization only if you need to join users from other domains.

    <figure><img src="../../../../.gitbook/assets/image (246).png" alt=""><figcaption></figcaption></figure>
5. **Save and Notify**:
   * Click "Create Group" to save the group.
6.  **Add Members**:

    * Add Owners to the group by selecting their emails.
    * Notify group members of the new email address.

    <figure><img src="../../../../.gitbook/assets/image (247).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Ensure group permissions are set correctly. Check for duplicate group names.
{% endhint %}
