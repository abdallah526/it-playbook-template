# Allow Quarantined mail

### Prerequisites

* Admin access to the Google Workspace Admin Console.
* The quarantined email details (e.g., sender, subject).
* A web browser (e.g., Chrome, Firefox).

### Steps

1. **Log in to Admin Console**:
   * Go to `https://admin.google.com/` and log in with admin credentials.
2.  **Navigate to Security**:

    * Click "Apps" > "Google Workspace" > "Gmail."
    * Click " GO TO ADMIN QUARANTINE".



    <figure><img src="../../../../.gitbook/assets/image (249).png" alt=""><figcaption></figcaption></figure>
3. **Locate the Email**:
   * Search for the quarantined email using sender or subject filters.
4.  **Allow the Email**:

    * Select the email and click "Allow" or "Deny"

    <figure><img src="../../../../.gitbook/assets/image (248).png" alt=""><figcaption></figcaption></figure>
5. **Save Changes**:
   * Confirm the action to release the email to the inbox.

{% hint style="info" %}
Review quarantine policies to prevent future blocks. Check logs for repeated quarantines.
{% endhint %}
