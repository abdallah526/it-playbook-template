# Create Email Account

### Prerequisites

* Admin access to the Google Workspace Admin Console.
* A verified domain (e.g., example.com).
* A web browser (e.g., Chrome, Firefox).

### Steps

1. **Log in to Admin Console**:
   * Go to `https://admin.google.com/` and log in with admin credentials.
2.  **Navigate to Users**:

    * Click "Manage Users" from the Main Screen.

    <figure><img src="../../../../.gitbook/assets/image (233).png" alt=""><figcaption></figcaption></figure>
3.  **Add a New Email Account**:

    * Click the "Add New User."
    * Enter the user’s first name, last name, and primary email (e.g., jsmith@example.com).
    * Click the "ADD NEW USER" button.

    <figure><img src="../../../../.gitbook/assets/image (235).png" alt=""><figcaption></figcaption></figure>

    <figure><img src="../../../../.gitbook/assets/image (236).png" alt=""><figcaption></figcaption></figure>
4. **Save and Notify**:
   * Copy the user credentials (email and password).
   * Notify the user of their credentials.
   * Click the "Done" button.
   *   Click "ADD ANOTHER USER" if you need to add multiple users.

       <figure><img src="../../../../.gitbook/assets/image (237).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Verify domain ownership if the account creation fails. Check user limits under your Google Workspace plan or contact the IT admin.
{% endhint %}
