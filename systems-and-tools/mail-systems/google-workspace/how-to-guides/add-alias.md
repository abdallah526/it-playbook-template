# Add Alias

### Prerequisites

* Admin access to the Google Workspace Admin Console.
* The primary email account and desired alias (e.g., jsmith@example.com).
* A web browser (e.g., Chrome, Firefox).

### Steps

1. **Log in to Admin Console**:
   * Go to `https://admin.google.com/` and log in with admin credentials.
2.  **Navigate to Users**:

    * Click "Users" and locate the primary email account.

    <figure><img src="../../../../.gitbook/assets/image (239).png" alt=""><figcaption></figcaption></figure>
3. **Add an Alias**:
   * Click the user’s email, then select "ADD ALTERNATIVE EMAILS."
   * Enter the alias (e.g., jsmith2@example.com).
   *

       <figure><img src="../../../../.gitbook/assets/image (238).png" alt=""><figcaption></figcaption></figure>
4. **Save Changes**:
   * Click "Save" to activate the alias.
5. **Notify the User**:
   * Inform the user they can use the alias to send/receive emails.

{% hint style="info" %}
Ensure the alias domain is verified. Check for duplicate aliases across accounts.
{% endhint %}
