# Reset Email Password

### Prerequisites

* Admin access to the Google Workspace Admin Console.
* The user’s email address (e.g., user@yourcompany.com).
* A web browser (e.g., Chrome, Firefox).

### Steps

1. **Log in to Admin Console**:
   * Go to `https://admin.google.com/` and log in with admin credentials.
2.  **Navigate to Users**:

    * Click "Users" from the left menu and locate the user.

    <figure><img src="../../../../.gitbook/assets/image (241).png" alt=""><figcaption></figcaption></figure>
3.  **Reset the Password**:

    * Hover on the user’s email, then select "Reset Password."
    * Enter a new password or generate one.

    <figure><img src="../../../../.gitbook/assets/image (242).png" alt=""><figcaption></figcaption></figure>
4. **Save Changes**:
   * Click "Reset" to update.
   * Notify the user of the new password securely.
5. **Verify**:
   * Ensure the user can log in with the new password.

{% hint style="info" %}
Ensure the new password meets Google’s security requirements. Check logs if the reset fails.
{% endhint %}
