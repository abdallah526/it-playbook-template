# Logging into Google

### Prerequisites

* A Google Workspace admin account with valid credentials.
* A web browser (e.g., Chrome, Firefox).
* Internet connection.

### Steps

1. **Navigate to Google Workspace**:
   * Open your web browser and go to `https://admin.google.com/`.
2. **Enter Credentials**:
   * Input your admin email address (e.g., admin@yourcompany.com) and password.
   * Click "Next."
3. **Handle Two-Factor Authentication (TFA)**:
   * If enabled, enter the TFA code sent to your registered device or app.
   * Click "Verify."
4. **Access the Admin Console**:
   * Once logged in, ensure you’re in the admin dashboard with options like "Users," "Domains," and "Security."
5. **Verify Login**:
   * Confirm access to email management tools.

{% hint style="info" %}
If login fails, verify your credentials or reset your password (see Reset Email Password). Clear browser cache if TFA issues persist.
{% endhint %}
