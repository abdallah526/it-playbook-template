# Quick Start

### Overview

Zoho Workspace is a cloud-based productivity suite that includes email management tools for businesses. It enables you to create and manage email accounts, secure your domain, reset passwords, handle two-factor authentication (TFA), delegate access, manage quarantined emails, and control allowlists/blocklists. This section provides quick access to essential tasks through the Mail Admin console.

### Key Features

* **Email Account Management**: Create and customize user email accounts.
* **Security**: Manage passwords, TFA, and email quarantine settings.
* **Domain Control**: Add domains to allowlists or blocklists and create aliases.
* **Collaboration**: Delegate email access to other users.
