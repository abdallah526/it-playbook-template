# Logging into Zoho

### Prerequisites

* A Zoho Workspace admin account with valid credentials.
* A web browser (e.g., Chrome, Firefox).
* Internet connection.

### Steps

1. **Navigate to Zoho Workspace**:
   * Open your web browser and go to `https://www.zoho.com/mail/`.
2. **Enter Credentials**:
   * Input your admin email address (e.g., jsmith@example.com) and password.
   * Click "Login."
3. **Handle Two-Factor Authentication (TFA)**:
   * If enabled, enter the TFA code sent to your registered device or app.
4. **Access the Admin Console**:
   * Once logged in, click on "Profile" and select "Admin Console".


1. **Verify Login**:
   * Ensure you’re in the admin dashboard with options like "Users," "Domains," and "Security."

{% hint style="info" %}
If login fails, verify your credentials or reset your password (see Reset Email Password). Clear browser cache if TFA issues persist.
{% endhint %}
