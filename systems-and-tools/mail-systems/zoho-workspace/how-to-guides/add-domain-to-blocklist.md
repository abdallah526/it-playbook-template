# Add Domain to blocklist

### Prerequisites

* Access to the Zoho Mail admin panel with administrative privileges.
* Knowledge of the domain to be added to the blocklist.

### Steps

1. Log in to the Zoho Mail admin panel.
2. Navigate to "Security & Compliance".
3. Click on "Spam Control".
4. Select "Blocked List".
5. Click the "+ Add" button.
6. Enter the domain name in the provided field.
7. Choose the action to apply by selecting "Mark as spam" or "Move to quarantine".
8. Click the "Add" button to confirm the action.

{% hint style="info" %}
Ensure the domain is correctly formatted (e.g., example.com) before adding it. Coordinate with your IT admin if emails from the blocked domain are still being delivered or if access issues arise. Verify spam settings if the desired action (e.g., quarantine) is not applied correctly.
{% endhint %}
