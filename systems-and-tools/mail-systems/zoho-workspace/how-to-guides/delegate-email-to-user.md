# Delegate Email to User

### Prerequisites

* Access to the Zoho Mail admin panel with administrative privileges.
* The user’s email account (e.g., John Smith) must be active in the Zoho Mail organization.
* The delegate user’s account must be active and identifiable in the system.

### Steps

1. Log in to the Zoho Mail admin panel.
2. Click "Users" and locate the source email account and click on it.
3. Navigate to "Mailbox Settings" under the user’s profile.
4. Click on "Delegated to".
5.  Click the "+ Add" button.



    <figure><img src="../../../../.gitbook/assets/image (64).png" alt=""><figcaption></figcaption></figure>
6. In the "Add users" popup, use the search field to find the delegate user.
7. Select the user from the list by checking the box next to their name.
8.  Click the "Submit" button to delegate the mailbox.



    <figure><img src="../../../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Ensure the delegate user’s account is active and properly configured in Zoho Mail. Coordinate with your IT admin to assign appropriate permissions (Read, Write, Send on Behalf, Send As) based on organizational needs. If the delegation fails or the delegate cannot access the mailbox, verify the user selection and check with your IT admin for assistance.
{% endhint %}

{% hint style="info" %}
Monitor delegated access for security. Revoke access if no longer needed.
{% endhint %}
