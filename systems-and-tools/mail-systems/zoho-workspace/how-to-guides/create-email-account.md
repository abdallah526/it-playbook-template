# Create Email Account

### Prerequisites

* Admin access to the Zoho Mail Admin console.
* A verified domain (e.g., yourcompany.com).
* A web browser (e.g., Chrome, Firefox).

### Steps

1. **Log in to Mail Admin**:
   * Go to [`https://mailadmin.zoho.eu/`](https://mailadmin.zoho.eu/) and log in with admin credentials.
2.  **Navigate to Users**:

    * Click "Users" from the left menu.

3.  **Add a New Email Account**:

    * Click "Add."
    * Enter the first and last name, and email address (e.g., jsmith@example.com) and set an initial password.
    * Check "Force user to change password on first log in".
    * Click "Add".

    <figure><img src="../../../../.gitbook/assets/image (100).png" alt=""><figcaption></figcaption></figure>
4.  **Save and Notify**:

    * Copy the email address and password, then click Done.
    * Notify the user of their credentials.

    <figure><img src="../../../../.gitbook/assets/image (101).png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
Verify domain ownership if the account creation fails. Check user limits under your Zoho plan
{% endhint %}
