# Allow Quarantined mail

### Prerequisites

* Access to the Zoho Mail admin panel with administrative privileges.
* The quarantined emails must be visible under the "Quarantine" section.
* Knowledge of the specific email to be delivered.

### Steps

1. Log in to the Zoho Mail admin panel.
2. Navigate to "Security & Compliance."
3. Click on "Quarantine."
4. Select "Incoming" under the quarantine settings.
5. Click the "Deliver selected" button.
6. Choose the specific email (e.g., "Let's Connect About...") by checking the box next to it and click "Deliver."
7. You can select "Deliver selected" to only deliver the selected mails or "Deliver and Add" to add the domain of email to the allowlist.

{% hint style="info" %}
Ensure the administrator has the necessary permissions to manage quarantined emails. Coordinate with your IT admin if the email remains quarantined after delivery or if access issues arise. Verify the spam settings if multiple emails need to be released regularly.
{% endhint %}
