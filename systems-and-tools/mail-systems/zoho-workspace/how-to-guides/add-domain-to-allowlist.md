# Add Domain to allowlist

### Prerequisites

* Access to the Zoho Mail admin panel with administrative privileges.
* Knowledge of the domain to be added to the allowlist.

### Steps

1. Log in to the Zoho Mail admin panel.
2. Navigate to "Security & Compliance".
3. Click on "Spam Control".
4. Select "Allowed List".
5. Click the "+ Add" button.
6. Enter the domain name in the provided field.
7. Click the "+ Add" button to save the domain to the allowlist.

{% hint style="info" %}
Ensure the domain is correctly formatted (e.g., example.com) before adding it. Coordinate with your IT admin if emails from the allowed domain are still being quarantined or blocked. Verify spam verification rules if issues persist.
{% endhint %}
