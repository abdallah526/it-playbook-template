# MSI Installation Error : 2502

### Steps

1. Go to **Local Disc (C:)** and open the **Windows** folder.
2. Find the **Temp** folder and right-click on it.
3. Go to **Properties** >>> **Security tab** >>> **Advanced**.
4. Click on your Windows user and change the permission to **Full control**.
5. Click **Apply**.
6. If you receive warning messages, click **Yes** and continue.
7. Install Sophos Connect again.
