# Introduction

## Welcome

This playbook is the single place where the IT team keeps how things work, how to fix them, and who to ask. Replace this paragraph with one or two lines about your team.

## What you will find here

* How the network and the main systems are set up.
* Step-by-step guides for daily tasks.
* What to do when something breaks.
* Team roles, approval rules and policies.

{% hint style="info" %}
New to the team? Start with [New Team Member Onboarding](start-here/new-team-member-onboarding.md).
{% endhint %}

## Using this template

1. Create your own copy of this repository (**Use this template** on GitHub, or download it).
2. In GitBook, create a space and connect it with **Git Sync**, choosing **GitHub → GitBook** for the first sync.
3. Replace the example names, addresses and tables with your team's details. Duplicate the template pages (site, system, alert, runbook, how-to) as you need them.
4. The filled-in guides (Active Directory, Sophos, VoIP phones, Google Workspace, Zoho, TeamViewer and more) are examples. Names, domains and addresses in them are placeholders (`company.local`, `example.com`, `172.20.x.x`). Keep what matches your tools and delete the rest.

{% hint style="info" %}
Keep passwords and other secrets out of the playbook. Point to where they are stored instead.
{% endhint %}
