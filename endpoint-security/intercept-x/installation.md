# Installation

### Prerequisites

* A device (Windows, macOS) to install Intercept X on.
* Sophos Central credentials, provided by the IT admin via Keeper Security.
* An active internet connection for downloading and activating the software.

### Steps

1.  **Log in to Sophos Central**:

    * Open a web browser and navigate to the Sophos Central login page.
    * Sign in using the credentials provided by the IT admin via Keeper Security.

    <figure><img src="../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>
2.  **Navigate to Installers**:

    * From the dashboard, click **My Products** and select **Endpoint**.
    * Click **Installers**.

    <figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>
3.  **Download the Installer**:

    * In the Installers section, locate the **Endpoint Protection** section.
    * Click **Download Complete Windows Installer** for a Windows device or **Download Complete macOS Installer** for a macOS device.

    <figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>
4.  **Install Intercept X**:

    * Run the downloaded installer on the device.
    * Follow the on-screen prompts to complete the installation.

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt="" width="563"><figcaption></figcaption></figure></div>
5. **Verify Installation**:
   * Return to the Sophos Central portal and navigate to **Computers** under Endpoint Protection.
   * Confirm the device appears in the list with Intercept X installed.

{% hint style="info" %}
Ensure the device is online during installation. If the device does not appear in Sophos Central, verify the installer version and internet connection.
{% endhint %}
