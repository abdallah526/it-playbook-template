# Quick Start

### Overview

* **Purpose**: Provides a unified platform for managing Sophos security solutions like Firewall Management and Intercept X.
* **Access**: Managed via the Sophos Central web portal; credentials provided by the IT admin via Keeper Security.
* **Key Areas**: Features include centralized threat monitoring, endpoint protection, and firewall management.

{% hint style="info" %}
Retrieve credentials from Keeper Security. Contact the IT admin for setup assistance.
{% endhint %}
