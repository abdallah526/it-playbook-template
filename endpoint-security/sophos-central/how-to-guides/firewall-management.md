# Firewall Management

### Prerequisites

* Access to the Sophos Central web portal.
* Sophos Central credentials, provided by the IT admin via Keeper Security.
* A web browser (e.g., Chrome, Firefox).

### Steps

1.  **Log in to Sophos Central**:

    * Open a web browser and navigate to the Sophos Central login page.
    * Enter your email address and click **Continue**.
    * Sign in using the credentials provided by the IT admin via Keeper Security.

    <figure><img src="../../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>
2.  **Access Firewall Management**:

    * From the Sophos Central dashboard, click **My Products** in the top navigation bar.
    * Select **Firewall Management** from the dropdown menu to access firewall settings.
    * Select **Firewalls**.

    <figure><img src="../../../.gitbook/assets/image (43).png" alt=""><figcaption></figcaption></figure>
3. **View Firewall Status**:
   * In the Firewall Management section, click **Firewalls** in the left sidebar.
   * Review the list of firewalls (e.g., HQ-FW.company.local, BRANCH-A-FW.company.local) and their status (e.g., Connected, Last seen 2 months ago).
   * Check the number of alerts (e.g., 8 alerts for HQ-FW.company.local) and connectivity details (e.g., IP Address, Model).
   * You can open the firewall's web admin by clicking on the name of the firewall.

{% hint style="info" %}
If a firewall shows "Last seen 2 months ago" (e.g., BRANCH-B-FW.company.local), it may be offline—escalate to the IT admin for troubleshooting. Regularly monitor alerts for potential issues.
{% endhint %}
