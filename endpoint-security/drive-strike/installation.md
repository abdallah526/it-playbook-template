# Installation

### Prerequisites

* A device (Windows, macOS, Android, or iOS) to install DriveStrike on.
* DriveStrike credentials, provided by the IT admin via Keeper Security.
* An active internet connection for downloading and activating the software.

### Steps

1.  **Log in to the DriveStrike Portal**:

    * Open a web browser and navigate to the DriveStrike web portal. [https://app.drivestrike.com/account/login/](https://app.drivestrike.com/account/login/)
    * Log in using the credentials (username and password) provided by the IT admin via Keeper Security, as shown in Figure 1.

    <figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>

    * Click **Login** to access the portal.
2.  **Download the DriveStrike Agent**:

    * In the portal, navigate to the **Install** section.
    * Click **Click here to install on Windows** to download the setup.exe file.

    <figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>
3. **Install the DriveStrike Agent**:
   * Locate the downloaded setup.exe file in your Downloads folder.
   * Double-click the file to run the installer and follow the on-screen prompts to complete the installation.
4.  **Register the Device**:

    * After installation, the DriveStrike setup wizard will open.
    * Enter the email address ([it@example.com](mailto:it@example.com)) provided by the IT admin.
    * Click **Register** to proceed.

    <figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>
5. **Verify Installation**:
   * Return to the DriveStrike web portal and check the device list to confirm your device appears as active and online.

{% hint style="info" %}
Ensure the device is online during registration. If the device does not appear in the portal, verify the email address and internet connection. Keep the DriveStrike agent updated for optimal performance.
{% endhint %}
