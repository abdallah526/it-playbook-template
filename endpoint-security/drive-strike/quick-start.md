# Quick Start

### Overview

* **Purpose**: Protects company devices with remote lock, wipe, and tracking capabilities.
* **Access**: Managed via the DriveStrike web portal; credentials are provided by the IT admin via Keeper Security.
* **Key Areas**: Features include device monitoring, data protection, and remote management for lost or stolen devices.

{% hint style="info" %}
Retrieve credentials from Keeper Security. Contact the IT admin for setup assistance.
{% endhint %}
